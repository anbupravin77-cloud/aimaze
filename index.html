How the 4 Classroom Data Structures Power This Maze

01 · CIRCULAR QUEUE (10 SLOTS)

Stores the last 10 moves in a fixed ring array [0..9]. When slot 9 fills, REAR = (REAR + 1) % 10 wraps around to slot 0 in O(1) time without shifting array items.

02 · NORMAL FIFO QUEUE

Adds neighbor tiles at REAR and removes from FRONT (First-In, First-Out) to check level-by-level that walls haven't blocked the Goal, and highlights the shortest hop route.

03 · LINKED LIST STACK (LIFO)

Every step taken during a run is Pushed onto TOP. When the run finishes at Goal (+100) or Trap (-50), steps are Popped in reverse order (Last-In, First-Out) so the rover traces backward to Start and updates tile scores.

04 · SINGLY LINKED LIST

Each tile has an edgesHead pointer linking its valid moves (UP → RIGHT → DOWN → LEFT → NULL). Walls are omitted; Portals link across the board.
